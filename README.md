<h3 align="center">Full stack engineer · Kolkata, India</h3>

---

Six years building web and mobile products end to end. React and TypeScript on the front, Node and NestJS behind it, PostgreSQL and Redis underneath. I've shipped interfaces used by tens of thousands of people, APIs handling ten thousand-plus requests a day, and a Flutter app sitting at 4.3 on the Play Store. Along the way I've led a team of five and mentored three junior engineers.

The work I like most is where state gets awkward: auth and sessions, ordering flows, a cache sitting in front of a database, realtime updates that have to agree with what was just written.

Lately I've been fine-tuning models and serving them behind APIs, and authoring evaluation tasks for coding-agent benchmarks. That second one means building the environment, the reference solution and the verifier, then calibrating the task until a strong agent fails it for the right reasons rather than the wrong ones. It has changed how I write tests.

**Stack:** TypeScript · Python · Node / NestJS · Next.js · React · Django · Prisma · PostgreSQL · Redis · Docker · AWS · Flutter
